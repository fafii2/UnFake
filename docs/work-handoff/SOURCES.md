# UnFake Phase 2 evidence sources

Public documentation checked 2026-11-05. The UnFake paper and SRS cite VERA Files, Tsek.ph, and live search. The current checkout has four reviewed VERA Files debunks and a configurable Tavily adapter. The five priority sources were checked against their public documentation. API availability and account quotas were not tested with credentials. Confirm reuse terms for specific material before import.

## Initial integration scope

| Source | Effort and verification gate |
| --- | --- |
| VERA Files and Tsek.ph | Low engineering effort through the existing reviewed import format. Editorial effort grows with archive size. Confirm article-level rights and original ratings before accepting new records. |
| PSA OpenSTAT | Moderate effort for one series adapter. Query one published table, validate its metadata and period against the official release, and exercise rate limiting before broadening coverage. |
| BSP | Low effort for direct links and curated releases. Structured automation depends on a stable, permitted endpoint for the chosen series. Start with publisher-supplied tables. |
| Tavily | Low adapter effort because an implementation exists. Account limits, terms, and query privacy are the main pilot gates. Verify dated results and 429 fallback with approved public queries before enabling. |

## Selection and evidence policy

Seed the local SQLite archive with reviewed VERA Files records and approved Tsek.ph material. Track article rights and the original rating with the publisher URL and date. Include supported, contradicted, mixed, and insufficient-evidence cases in the evaluation set. The four bundled debunks are a development sample. Review updates and corrections periodically, and preserve the applicable time window when using archived ratings.

For current claims, start with an original issuer when the question has an official answer, such as a PSA release or BSP series. Use independent reporting and published fact checks to confirm context. A candidate that repeats the claim, quotes it without evaluating it, or refers to another place or period is contextual. Resolve redirects and syndication before counting independence. Retain the smallest excerpt necessary and the canonical original source. A missing result from one or all providers leads to an explicit coverage limit.

For a live pilot, reuse the Tavily adapter after privacy and license approval. Start with a domain allowlist and redact irrelevant personal data before dispatch. Keep claims containing sensitive information in the offline path. Keep provider credentials on the backend. Avoid provider-generated summaries as primary evidence, and turn off paid overage. The current adapter sends the claim and uses the basic search endpoint. Phase 4 should minimize the external query, verify publication dates, and record typed provider failures. On 429 or timeout use the local archive and a visible notice. Use bounded retries only when the remaining deadline and quota permit them.

Before enabling a source, record the terms checked, a permitted use category, sample response and error behavior, Philippine language and topic coverage, date reliability, independence, and evidence rights. On a reviewed sample, compare relevant-source recall and unique canonical links against the offline archive. Test false matches, outdated results, and an empty or unavailable provider. Only pre-approved public inputs should enter external provider tests. Exact account limits, dataset reuse permissions, and live coverage remain Phase 4 checks.
